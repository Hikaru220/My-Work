# ВЕРЕЯ — демо-лендинг дверного ателье

Одностраничный имиджевый сайт для интерьерных/межкомнатных дверей — демо-пример
для показа заказчику, вдохновлённый эстетикой каталога Волховец, но выстроенный
как отдельный лендинг, а не карточка товара.

- **Стек:** React 19 + TypeScript, Tailwind CSS v4, Motion (framer-motion) для анимаций.
- **Контент:** бренд, номер WhatsApp/телефон и цены — заглушки для демонстрации,
  см. пометки `ЗАГЛУШКА ДЛЯ ДЕМО` в [`src/data/content.ts`](src/data/content.ts).
- **Сборка:** `npm run dev` для разработки, `npm run build` собирает статику
  прямо в `../dveri` (соседняя папка в репозитории) — так GitHub Pages отдаёт
  готовый сайт по пути `/dveri/` без отдельного шага сборки в CI.

## Особенности реализации

- Мобильная шапка сворачивает навигацию в fullscreen-меню по гамбургеру.
- Плавающая кнопка WhatsApp закреплена поверх контента на всех разрешениях —
  полноширинная плашка на телефоне, пилюля с пульсирующим кольцом на десктопе.
- Калькулятор стоимости считает цену по выбранной коллекции, количеству и
  опциям (монтаж, доборы) и формирует готовое сообщение в WhatsApp.
- Все скролл-анимации через `whileInView`/`useScroll` из Motion, с уважением
  `prefers-reduced-motion` через `MotionConfig`.
